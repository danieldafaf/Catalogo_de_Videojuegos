# Catálogo de Videojuegos

Este proyecto consiste en una aplicación de consola desarrollada en Java 25 que permite registrar y consultar videojuegos mediante un menú interactivo.

1. Registrar videojuegos.
2. Mostrar los videojuegos registrados.
3. Validar el nombre y la plataforma.
4. Validar el año de lanzamiento y el precio.
5. Controlar entradas numéricas incorrectas.
6. Verificar si existe espacio disponible en el arreglo.
7. Salir del programa.

- Main.java: contiene el menú y la lógica principal.
- Videojuego.java: contiene el record con los atributos de cada videojuego.

- Nombre.
- Plataforma.
- Año de lanzamiento.
- Precio.
